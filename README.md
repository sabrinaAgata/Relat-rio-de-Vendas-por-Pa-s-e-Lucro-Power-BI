Relatório de Vendas por País e Lucro — Power BI

Sobre o projeto

Este projeto faz parte do desafio prático de Power BI da plataforma DIO, com foco na criação de relatórios interativos para análise de dados financeiros e comerciais.

O objetivo é desenvolver um dashboard que permita visualizar e analisar indicadores de vendas, lucro e unidades vendidas, facilitando a identificação de resultados por país e segmento de negócio.

Objetivos

* Analisar o desempenho de vendas e a geração de lucro.
* Comparar os resultados entre diferentes países.
* Identificar os segmentos com maior participação nos lucros.
* Desenvolver visualizações claras e interativas para apoiar a análise dos dados.

Estrutura do relatório

O relatório será desenvolvido no Power BI Desktop e contará com três páginas:

Página 1 — Visão geral

Reprodução da primeira página de referência apresentada no desafio da DIO.

Página 2 — Análise financeira

Reprodução da segunda página de referência apresentada no desafio da DIO.

Página 3 — Distribuição de lucros, vendas e unidades vendidas por país e segmento

Página autoral com visualizações para analisar:

* Vendas e unidades vendidas por país.
* Lucro por país.
* Distribuição do lucro por segmento.

Ferramentas e tecnologias

* Power BI Desktop: criação e desenvolvimento do relatório.
* Microsoft Excel: fonte de dados financeiros.
* GitHub: documentação e versionamento dos arquivos do projeto.

Fonte de dados

O projeto utiliza a amostra financeira Financial Sample, com dados de vendas, lucro, unidades vendidas, países e segmentos.

Aprendizados

O desenvolvimento deste projeto tem como objetivo praticar a importação e organização de dados, a construção de visualizações, a análise de indicadores e a elaboração de relatórios interativos utilizando o Power BI.
